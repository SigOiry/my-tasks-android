Why this order?

Smart ranks all eligible actionable tasks together: overdue 50, today 40, tomorrow 25, within 7 days 10; high 30, medium 15; in progress 6, new update 6; each full week old 1 (up to 4). Waiting follows actionable work; finished tasks follow waiting. Ties: due date, importance, oldest creation, task ID. Reverse changes the main ranking, not these tie-breaks.

Private session

Authentication uses a secure server cookie. Passwords are never saved by this app in browser storage. Tasks and loaded discussions stay in page memory; conversation history persists privately on the server. Preferences and an opaque alert cursor are stored locally. Signing out clears local state, not saved server history.

About Hermès

Questions, analysis and drafts using saved conversation history. Hermès has no tools and cannot send email or change tasks. Voice transcription is optional, editable and never sent automatically; your browser may use a remote speech service.
