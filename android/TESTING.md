## Updater matrix — NOT executed

The updater implementation/provider and independent executor remain unchanged. Existing host tests reject downgrade/same version, wrong package/signer/hash/size/schema/type/asset, untrusted URLs/ports/user-info/traversal, redirect loops, oversized/short streams, cancellation and stale consent generations. APK metadata generation is independently tested. These tests do not prove Android installation.

1. Manual original-signed upgrade from older releases; reject another signer. Fresh no-account manual **Check for updates** works independently of task server and pending chats. Automatic check happens once per foreground local day; rotation/resume joins single-flight work. Offline/404/403/429/timeout/TLS/JSON failure is quiet automatically but visible manually.
2. Version/notes offer requires Update acceptance; Later/back does not download. Preserve lifecycle ownership. Cancel/rotate/background slow downloads; obsolete generations cannot open installer. Wrong hash/size/package/version/signer never reaches installation and temporary files are removed.
3. Unknown-source permission on API26+ is explained and user-opted-in. Deny/back does not install; returning with permission re-verifies the accepted file. Revocation/MDM/OEM/no-installer fail safely; no root/silent installation or protection bypass. System confirmation still required.
4. Cancel/result revokes exact temporary grant and deletes file. Process death does not replay stored installation consent; startup clears stale downloads. Unaccepted files cannot trigger installation after Settings return.
5. Provider is non-exported/read-only: reject no-grant/old/guessed/changed URI, query/path/authority tampering, `_data`, write modes, insert/update/delete and arbitrary filesystem paths. Only the currently accepted exact capability can read the public verified APK during its active installer flow.
6. Re-run task/chat state and draft cases while updater checks/downloads operate. Save before accepting installation; replacing the process can discard unsaved memory. No native updater/Keystore/installer success is asserted without device evidence.
