INSTALL IN YOUR HERMES INSTANCE
1. Make this ZIP available to Hermes as a file attachment or in a location its
   terminal can read. Do not paste image bytes or a private key into chat.
2. Ask Hermes to back up its existing native-android-liquid-glass skill, then
   install this complete folder under its active HERMES_HOME/skills directory.
   Your known HERMES_HOME is /opt/data, so the normal destination is:
   /opt/data/skills/native-android-liquid-glass/
3. Keep assets/, references/ and SKILL.md together; do not install just SKILL.md.
   Do not nest the folder twice or put unrelated kit files inside skills/.
4. Confirm the loaded skill reports version 3.0.0 and that Hermes can open the
   preview PNGs using its vision tool.
5. Start a fresh chat or refresh skills as supported by your installed Hermes.
   Paste IMPLEMENTATION-PROMPT.txt. It begins with /native-android-liquid-glass.
